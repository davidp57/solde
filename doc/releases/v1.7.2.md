# Notes de version — Solde ⚖️ v1.7.2

**Date de publication :** 2026-05-12

---

## Résumé

Cette version regroupe les livraisons depuis la v1.6.0 avec un focus sur trois axes :
- fiabilisation des sauvegardes (dont OneDrive),
- nouveau cycle de vie des factures archivées,
- amélioration des performances d'affichage des grandes listes.

### Points majeurs

- **Feature majeure : Sauvegarde automatique** (planification, destinations multiples, restauration, notifications, OneDrive device code + Microsoft Graph, suivi temps réel).
- **Feature majeure : Import des factures historiques Word** (mode dry-run/commit, rattachement PDF existant, reprise du montant déjà réglé, rapport détaillé).

---

## Nouveautés

### Sauvegardes automatiques (lot BK)

- Planification enrichie : intervalle, cron, et mode **quotidien HH:MM**.
- Destinations de sauvegarde : local, SMB, OneDrive.
- Option **inclure tous les backups précédents** (sinon envoi du dernier snapshot seulement).
- Suivi temps réel de l'exécution et meilleure visibilité des sauvegardes planifiées en cours.
- Flux d'autorisation OneDrive par **device code** et transfert direct via API Microsoft pour une meilleure robustesse en environnement Docker/NAS.

### Facturation (lot FW)

- Nouveau statut **Archivée** pour les factures client payées (état terminal).
- Endpoint d'archivage en masse des factures payées sélectionnées.
- Script d'import Word `scripts/import_word_invoices.py` pour l'historique de facturation (`.docx`) avec rapport d'import.
- Bouton **Exporter Excel** généralisé sur les vues DataTable.

### Listes volumineuses

- Paramètre global **Limite d'affichage par défaut** (500 par défaut).
- Bannière d'avertissement quand des éléments restent côté serveur.
- Désactivation possible par session utilisateur (chargement jusqu'au plafond API : 5 000).
- Exposition du total serveur via en-tête `X-Total-Count` sur les endpoints de liste principaux.

### Contacts

- Fonction de **fusion de contacts** (dialog frontend + endpoint backend) pour traiter les doublons.

---

## Corrections

- Aperçus PDF : compatibilité améliorée sur Chrome (rendu et comportements d'aperçu intégrés).
- Factures payées : filigrane **PAYÉ** sur les PDF.
- Sauvegarde automatique : correction de l'affichage du spinner quand le déclenchement est planifié pendant que la page est déjà ouverte.

---

## Technique

- Refactoring backend : standardisation des erreurs API et suppression des `commit` applicatifs au profit du cycle transactionnel de `get_db()`.
- Découpage du routeur banque en sous-routeurs spécialisés.
- Renforcement des validations backend (notamment paramètres de limite de liste).
- Extension des tests backend/frontend sur les nouvelles fonctionnalités (backup, archivage, pagination, imports, vues).
