# Notes de version — Solde ⚖️ v1.4.0

**Date de publication :** 3 mai 2026

---

## Résumé

Cette version regroupe trois lots de travaux réalisés sur la branche `develop` depuis la v1.3.0 :

- **Lot CR** — Correctifs de sécurité et de qualité (TEC-133 à TEC-141, TEC-155)
- **Lot UI** — Améliorations UX et API (BIZ-149, BIZ-150, BIZ-157, BIZ-158)
- **Lot DOC** — Amélioration de la documentation utilisateur en ligne (BIZ-161, BIZ-162, BIZ-163)
- **TEC-156** — Correction du bug d'authentification de l'assistant IA

---

## Sécurité (Lot CR)

- **TEC-133** — Le jeton d'accès JWT est désormais stocké **uniquement en mémoire Pinia**, sans jamais passer par `localStorage`. La session est restaurée silencieusement au rechargement via le cookie HttpOnly de rafraîchissement — atténuation XSS.
- **TEC-135** — Protection contre la **race condition sur la numérotation des factures** : boucle de retry sur `IntegrityError` (jusqu'à 3 tentatives) sans verrou explicite.
- **TEC-134** — `record_audit()` maintenant appelé avant `await db.commit()` dans `update_user` — atomicité audit/modification restaurée.
- **TEC-136** — Les chemins de fichiers de factures sont stockés en **relatif** en base de données ; la résolution absolue n'est effectuée qu'à la lecture.
- **TEC-137** — Le payload JWT est décodé une seule fois par middleware et mis en cache dans `request.state.jwt_payload` ; `get_current_user` le réutilise sans second décodage.
- **TEC-138** — Rate limiter : purge périodique des clés expirées toutes les 100 tentatives pour borner l'empreinte mémoire.
- **TEC-139** — Tokens OpenAI correctement comptabilisés en mode streaming (`stream_options={"include_usage": True}`).
- **TEC-140** — `GET /api/settings/audit-logs` : pagination (`skip`/`limit`) et filtres (`action`, `actor_id`, `from_date`, `to_date`).
- **TEC-141** — Constante `USER_ROLES` dans `frontend/src/constants/roles.ts` : source unique pour les chaînes de rôles côté frontend.
- **TEC-155** — Suppression des 13 `# type: ignore[return-value]` dans `backend/routers/invoice.py` (annotations corrigées).

---

## Améliorations UX et API (Lot UI)

- **BIZ-158** — La limite par défaut des API de liste est portée à **1 000 éléments** (factures, paiements, contacts, transactions bancaires, dépôts, salaires). Un bandeau d'avertissement s'affiche quand le résultat atteint cette limite.
- **BIZ-157** — Les DataTables affichent désormais **50 lignes par défaut** (au lieu de 20).
- **BIZ-149** — La première lettre d'un libellé de ligne de facture est **automatiquement mise en majuscule** au `blur`.
- **BIZ-150** — Les champs quantité et prix unitaire dans `ClientInvoiceForm` acceptent la **virgule comme séparateur décimal** (normalisée en point à la saisie).

---

## Documentation utilisateur en ligne (Lot DOC)

- **BIZ-161** — Nouvel onglet **« Nouveautés »** dans la page Aide : affiche le changelog utilisateur rendu en Markdown via l'endpoint `GET /api/help/changelog`.
- **BIZ-162** — Les **liens d'ancre** dans le manuel en ligne défilent maintenant vers la section cible avec une marge correcte par rapport à l'en-tête fixe. Les liens vers des titres avec accents fonctionnent correctement.
- **BIZ-163** — Un **guide par rôle « Je veux… »** est ajouté en fin de manuel : index des activités par rôle (Secrétaire, Trésorier, Administrateur) avec liens directs vers les sections concernées.

## Correction de bug

- **TEC-156** — L'assistant IA (chatbot) retournait systématiquement une erreur **401** car il lisait le jeton d'authentification depuis `localStorage` (toujours vide depuis TEC-133). Corrigé : le jeton est désormais lu depuis le store Pinia en mémoire.
